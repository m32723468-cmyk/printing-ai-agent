\# Printing AI Agent



An AI-powered customer service agent for a printing and graphic design business.



\## Project Goal



Build an intelligent AI assistant that can communicate with customers, understand their requests, calculate prices, retrieve business information, and manage customer orders.



\## Technology Stack



\- Python 3.13.7

\- Ollama

\- Qwen 3.5 4B

\- Pydantic (planned)

\- ChromaDB (planned)

\- SQLite (planned)

\- FastAPI (planned)

\## Planned Features



\### 1. Customer Service

\- Understand customer requests.

\- Support Darija, Arabic, French and English.

\- Collect order details.



\### 2. Tools

\- Price calculator.

\- Service search.

\- Quote generation.



\### 3. RAG

\- Retrieve information from business documents.

\- Search services and prices.



\### 4. Memory

\- Remember relevant customer information.

\- Maintain conversation context.



\### 5. Planning

\- Organize tasks.

\- Select appropriate tools.

\- Request human approval when necessary.
